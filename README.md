# Real-Time Air Quality Monitoring System using IoT

## Project Description
This project monitors indoor air quality using ESP32, MQ-135, MQ-7 and DHT22 sensors.

## Hardware
- ESP32
- MQ-135
- MQ-7
- DHT22
- Relay Module
- DC Exhaust Fan
- Buzzer

## Software
- Arduino IDE
- ThingSpeak

## Features
- Real-time air-quality monitoring
- Temperature and humidity monitoring
- Automatic exhaust fan control
- Buzzer alert
- ThingSpeak cloud monitoring
